# 主动显示密码

按自定义快捷键，切换当前聚焦密码框的明文 / 密文，不依赖网站自带的「显示密码」按钮。

- 版本：0.2.1
- 源码：[`ScriptCat/主动显示密码.user.js`](../ScriptCat/主动显示密码.user.js)
- 安装：[点此安装](https://raw.githubusercontent.com/Qiscard/Favorite-script/main/ScriptCat/主动显示密码.user.js)
- 适用：所有网站（`*://*/*`）
- 依赖：[ScriptCat](https://scriptcat.org/) / Tampermonkey / Violentmonkey 等脚本管理器

## 功能

- **快捷键切换**：默认 `Alt+P`，把当前聚焦的密码框在密码与明文之间切换，无视站点是否有「显示密码」按钮。
- **两种模式**：按住快捷键显示明文、松开恢复；或每按一次切换一次。
- **提示气泡**：切换时在密码框上方短暂提示「已显示 / 已隐藏」，可关闭。
- **即时生效**：设置面板保存后无需刷新页面，正在打开的页面立刻按新快捷键工作。
- **兼容特殊场景**：支持焦点位于 Shadow DOM（如部分登录组件）与 iframe 内的密码框；切换后尽量保留光标与选区位置。

## 快捷键写法

| 写法 | 效果 |
| --- | --- |
| `Alt+P` | 同时按下 Alt 与 P |
| `Ctrl+Shift+U` | 组合键，修饰键用 `+` 连接，大小写不限 |
| `F8` | 单个功能键 |
| `Ctrl` / `Alt` / `Shift` / `Meta` | 只写修饰键：快速点按一次触发（配合「按住才显示」则是按住 0.3 秒） |

修饰键可写 `Ctrl`、`Alt`、`Shift`、`Meta`（Mac 上的 Command），主键支持字母、数字、功能键与 `Esc` / `Enter` / `Space` / `Delete` / `Tab` / 方向键等常用键名。

## 设置

脚本菜单「显示密码设置」中可调整：

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 切换快捷键 | `Alt+P` | 按上表写法填写，保存后立即生效 |
| 按住才显示 | 关 | 开启后按住显示、松开恢复；关闭则每按一次切换一次 |
| 显示提示 | 开 | 是否在密码框附近闪一下「已显示 / 已隐藏」 |

## 使用说明

1. 点击（或用 `Tab` 聚焦）页面上的密码框。
2. 按下快捷键，密码变为明文；再按一次恢复。
3. 部分页面的密码框由框架接管、切回时会重置 `type`，脚本会在你继续输入后自动清理标记，避免状态错乱。

**限制**：浏览器自身保留的快捷键（如 `Ctrl+T`、`Ctrl+W`、`F5`）无法被脚本覆盖，请避开这些组合。

## 隐私

脚本只修改输入框的 `type` 属性，不读取、不保存、不上传任何输入内容，也没有任何网络请求。
