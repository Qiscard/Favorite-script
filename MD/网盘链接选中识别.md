# 网盘链接选中识别

拖选网页文字时，自动识别其中的网盘分享链接与提取码，弹出小卡片显示链接是否有效，可一键打开或复制。

- 版本：1.1.0
- 源码：[`ScriptCat/网盘链接选中识别.user.js`](../ScriptCat/网盘链接选中识别.user.js)
- 安装：[点此安装](https://raw.githubusercontent.com/Qiscard/Favorite-script/main/ScriptCat/网盘链接选中识别.user.js)
- 适用：所有网站（`*://*/*`）
- 依赖：[ScriptCat](https://scriptcat.org/) / Tampermonkey / Violentmonkey 等脚本管理器

## 功能

- **拖选即检测**：鼠标拖选任意网页文字，脚本扫描选区，只有识别到网盘链接时才弹卡片，纯文本选区不会打扰。
- **卡片跟随光标**：卡片出现在鼠标右下方，靠近窗口边缘时自动翻转，不会超出可视区域。
- **自动校验**：请求对应网盘的公开接口，确认分享是否仍然可用；带提取码的还会顺带校验提取码是否正确。
- **一键操作**：打开（提取码自动带上）或复制「链接 + 提取码」。
- **多种关闭方式**：点卡片右上角 ×、按 `Esc`、点页面空白处、页面滚动，都会关闭。

## 支持的网盘

| 类型 | 网盘 |
| --- | --- |
| 主流网盘 | 百度网盘、夸克网盘、UC 网盘、阿里云盘、天翼云盘、123 云盘、迅雷云盘、115 网盘、腾讯微云 |
| 其他网盘 | 蓝奏云（含优享版）、城通网盘、文叔叔、坚果云、小飞机网盘、360 云盘、移动云盘 |
| 无需校验 | 磁力链接（只识别，不校验有效性） |

## 状态说明

| 状态 | 含义 |
| --- | --- |
| 有效 | 分享可访问；带提取码的会一并校验提取码是否正确 |
| 已失效 | 分享被删除、过期或链接不存在 |
| 需要提取码 | 分享存在但需要提取码，或识别到的提取码不正确 |
| 无法校验 | 该网盘没有公开校验接口，需打开确认（如小飞机、360、移动云盘） |

识别到提取码时会以 `提取码 xxxx` 标签展示；识别不到的分享会显示为空码状态。

## 设置

脚本菜单中可暂停检测，或打开设置：

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 拖选自动检测 | 开 | 关闭后拖选不再触发检测 |
| 自动检测链接有效性 | 开 | 关闭后仍识别链接，但不再请求网盘接口 |
| 识别磁力链接 | 开 | 是否识别 `magnet:` 链接 |
| 单次最多显示 | 5 | 一次选区中最多展示的链接条数（1–10） |
| 自动关闭 | 0 | 卡片停留多少秒后自动关闭，0 表示不自动关闭 |

## 设计说明

- 判定结果缓存 10 分钟，重复选中同一链接不会反复请求接口。
- 接口请求失败或页面结构异常时显示「请打开确认」，而不是直接判为失效，避免误报。
- 百度网盘不使用 `shorturlinfo` 接口判断失效（该接口会把有效链接报成已删除），改为读取分享页本身：HTTP 404 视为不存在，`SHAREPAGETYPE = 'init'` 视为需要提取码，其余视为有效。
- 卡片使用 Shadow DOM 隔离，页面的 CSS 不会影响外观，也不会污染页面样式。
