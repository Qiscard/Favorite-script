# PikPak 分享下载助手

在 PikPak 分享页扫描目录、解析 CDN 预签名直链，推送到本机 aria2 按分享内目录结构下载；支持在线播放、单文件下载与列表导出。

- 版本：0.7.1
- 源码：[`ScriptCat/PikPak分享下载助手.user.js`](../ScriptCat/PikPak分享下载助手.user.js)
- 安装：[点此安装](https://raw.githubusercontent.com/Qiscard/Favorite-script/main/ScriptCat/PikPak分享下载助手.user.js)
- 适用：PikPak 分享页（`https://mypikpak.com/*`，面板只在 `/s/...` 分享页出现）
- 依赖：[ScriptCat](https://scriptcat.org/) / Tampermonkey / Violentmonkey 等脚本管理器；批量下载需要本机 [aria2](https://aria2.github.io/) 开启 RPC

## 功能

- **目录扫描**：扫描当前浏览的目录，或递归遍历整个分享目录树（自动翻页）。
- **目录内导航**：文件夹条目可直接点击「进入」，「⬆上级」返回上一层，不必回网页双击。
- **直链懒获取**：扫描只遍历目录，直链在推送 / 导出 / 播放 / 下载时才请求，接近过期会自动刷新。
- **推送 aria2**：按分享内的相对路径写入 `dir` / `out`，多连接分段、断点续传、失败重试；推送前会跳过 aria2 队列里已有的同名任务。
- **任务监控**：轮询显示排队 / 下载中 / 完成、实时速度、连接数、进度与错误；完成时核对文件大小是否与分享列表一致。
- **失败自动重推**：aria2 任务报错时自动重新取链并以单连接重推一次。
- **在线播放**：视频 / 音频可点击「播放」直接流播，不下载落盘。
- **单文件下载**：列表内「下载」按钮，≤200 MB 走内存转存保证文件名正确，更大的文件交给浏览器下载直写盘。
- **选择与筛选**：扩展名过滤、关键字搜索、按名称 / 大小排序、勾选（全选 / 反选），推送与导出只处理勾选项。
- **导出**：导出 aria2 输入文件（URL + `dir` + `out`）或纯直链文本，可离线 `aria2c -i`。
- **断点续扫**：递归扫描中止或中断后保存进度，下次可从断点继续；单个目录失败自动跳过并记录。
- **恢复扫描**：可恢复上一次的扫描结果（限同一分享），刷新页面后免重扫。
- **多凭证故障转移**：内置 3 套客户端凭证，某套签名失效时自动切换到可用的一直并记住。

## 使用说明

1. 安装脚本，打开任意分享页（`https://mypikpak.com/s/...`），右下角出现 **PikPak 下载助手** 按钮。
2. 点击按钮展开面板；如分享需要提取码，面板会显示「提取码」输入框，填写后重新扫描。
3. 在网页里双击进入目标子目录后点「扫描当前目录」，或直接点「扫描全部(递归)」扫整棵树。
4. 用过滤 / 搜索 / 勾选缩小范围，然后：
   - 点「推送 aria2」批量下载；或
   - 点「导出列表」生成 `aria2c -i` 可用的文件；或
   - 逐行点「播放」在线看、「下载」存单个文件、「复制」拿直链。

### aria2 准备

```bat
aria2c --enable-rpc --rpc-listen-all --rpc-allow-origin-all --rpc-secret=你的密钥
```

如果浏览器访问 PikPak 必须走代理，aria2 也要加同一个代理：

```bat
aria2c ... --all-proxy=http://127.0.0.1:7890
```

面板里「测试连接」可验证 RPC 是否可用。

## 设置

面板与 ScriptCat 的脚本设置表单（`==UserConfig==`）读写同一份配置：

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| aria2 RPC 地址 | `http://127.0.0.1:6800/jsonrpc` | aria2 开启 `--enable-rpc` 的地址 |
| RPC 密钥 | 空 | 对应 `--rpc-secret` |
| aria2 代理 | 空 | 需与浏览器访问 PikPak 的代理一致，否则任务可能 0 速度 |
| 保存根目录 | `D:/PikPak` | 分享内的目录结构会保留在它下面 |
| 优先转码 | 关 | 原画为 AV1 / HEVC 播放不了时优先取转码流 |

## 权限与登录

| 文件类型 | 是否需要登录 | 说明 |
| --- | --- | --- |
| 视频 / 音频 / 图片 | 否 | 分享接口可直接签发预签名直链 |
| 压缩包 / 文档 / 程序等 | 是 | 读取当前页面登录态；且脚本按分享策略只处理小于 100 MB 的非媒体文件 |

- 登录态从页面 `localStorage` 的 `credentials_*` 读取，只在内存中使用，不写入日志、导出文件或脚本存储。
- 面板顶部状态条：绿点=已登录（压缩包等可下），黄点=匿名（仅媒体）。

## 注意事项

- **直链会过期**：PikPak 直链是带签名和过期时间的临时 CDN 地址（通常约 38 小时），过期后需重新取链，不要把直链文本长期保存。
- **aria2 必须能出网**：aria2 不会继承浏览器代理，浏览器需要代理时务必填写「aria2 代理」，否则任务会入队但速度为 0。
- **编码兼容性**：原画常见 HEVC / AV1 / E-AC3，浏览器可能无法解码，这不影响下载；播放时可点「尝试转码流重试」，或下载后用 VLC / PotPlayer 播放。
- **大文件不建议走浏览器**：浏览器下载路径（尤其兜底 `<a>` 方式）在 CDN 不返回 `Content-Disposition` 时文件名可能不正确，大文件请用 aria2。
- **目录引用是加密的**：分享 URL 里 `share_id` 之后的段无法解析，脚本通过监听页面自身的 `share/detail` 请求来得知当前目录，所以「扫描当前目录」需要在页面上先进到目标文件夹。
- **超大分享扫描慢**：目录请求按约 300 ms 节流以避免风控；数万文件的分享建议先进子目录再扫描。

## 隐私

- 仅在 `mypikpak.com` 域内运行，登录 token 不落盘、不上传第三方。
- 导出的 aria2 列表与直链文件包含临时签名 URL，应视为敏感文件。
- RPC 不建议暴露到公网；`--rpc-listen-all` 只应在可信网络中使用并设置密钥。
- 请确认自己有权访问和下载所处理的分享内容，并遵守 PikPak 服务条款与当地法律。
